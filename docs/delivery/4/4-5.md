# [4-5] Add Velocity Damping (Kd_vel)

## Description
Add derivative term to the velocity PID loop (Kd_vel > 0) to reduce chattering and improve velocity-loop stability, once angle loop and velocity sign are solid.

## Status History
- 2026-02: Task file created; scope from PBI-4 prd.

## Requirements
1. Enable Kd_vel in velocity PID (currently PI-only).
2. Expose Kd_vel via serial/GUI and EEPROM.
3. Tune Kd_vel after Kp_vel/Ki_vel are stable (BALANCE_CODE_REVIEW Phase 1).

## Implementation Plan
1. Add Kd_vel to velocity PID in firmware; ensure derivative-on-measurement if applicable.
2. Add serial commands and SYNC for Kd_vel.
3. Add EEPROM save/load and validation for Kd_vel.
4. Tune with velocity setpoint 0 first, then small setpoints.

## Test Plan
1. Verify velocity loop remains stable with small Kd_vel.
2. Compare chattering (motor current oscillation) before/after.
3. Use log_evaluator on logs.

## Verification
- Kd_vel tunable and persisted; velocity loop stable; reduced chattering where applicable.
