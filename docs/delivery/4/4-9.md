# [4-9] Angle Loop — Gyro-Rate D-Term (Low-Lag Damping)

**Parent**: [Tasks for PBI 4](./tasks.md)

## Description

Implement derivative damping for the balance angle loop using BNO085 calibrated gyro rate (e.g. pitch/roll rate axis aligned with control) instead of relying solely on `PID_v1`’s `dInput` on EMA-filtered angle. Reduces phase lag during large disturbances where `AI` trails `R` by several samples.

## Status History

- 2026-04-16: Created as **Proposed**. Split from roadmap Phase B after field logs showed filter-limited D during pushes.

## Requirements

1. Define which gyro axis feeds the D-term and document sign relative to `RollOut`.
2. Combine with existing P (and optional filtered-D or remove duplicate D to avoid double-counting).
3. Clamp total command to existing `maxCurrent`; preserve dither and safety paths.
4. Loggable: `GAINS:` or equivalent documents effective gyro D gain.
