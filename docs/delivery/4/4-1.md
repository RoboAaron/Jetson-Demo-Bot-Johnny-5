## Description
Add velocity control loop (outer loop) to working single-loop balance controller, enabling controlled forward/backward movement while maintaining balance.

## Requirements
1. Read VESC encoder RPM and convert to velocity (m/s)
2. Implement velocity PID controller (outer loop)

## Key Learnings
1. **Motor Poles**: Corrected to 30 poles (15 pole pairs) for ERPM→RPM conversion
2. **Velocity Calculation**: `mech_rpm = erpm / pole_pairs`, then `mps = mech_rpm * π * wheel_diameter / 60`
3. **Stability Features**: EMA filter, deadband, clamping, and slew rate are essential for stable velocity loop
4. **Sign Verification**: Velocity PID direction must be REVERSE (not DIRECT) for correct control
5. **Deadband Handling**: State flag needed to prevent mode thrashing
