# [4-7] Balance Recovery — EEPROM Reset, Dither, Gain Logging

**Parent Tasks**: [Tasks for PBI 4](./tasks.md)

## Description
Execute steps 1–4 of the revised balance-recovery sequence developed after
field-log analysis of `tuning_code/logs/robot_log_20260415_222218.txt`. The
live robot was running gains from stale EEPROM rather than source-code
defaults, which made every tuning session a debug of an unknown controller.
This task (a) forces source defaults via a `SETTINGS_MAGIC` bump,
(b) sets known-good starting gains in source, (c) replaces the piecewise
`applyStictionComp()` (which creates a 0.55 A zero-crossing step → limit
cycle) with a zero-mean 40 Hz sinusoidal current dither, and (d) adds a
per-second `GAINS:...` line to the serial stream so every captured log is
self-documenting.

Scope is intentionally narrow: **no architecture, sign, IMU, or velocity-loop
changes.** Those belong to follow-up tasks (direct-gyro D-term, complementary
filter, outer-loop re-enable).

## Requirements
1. **R1 — EEPROM defaults forced**: Bump `SETTINGS_MAGIC` from `0xC45C4DEE` to
   `0xC45C4DEF` so `loadSettings()` returns false on next boot and source
   defaults take effect. `SavedSettings` struct layout unchanged.
2. **R2 — Known-good source defaults**: `Kp = 5.0`, `Ki = 0.0`, `Kd = 0.03`,
   `baseSetpoint = -1.60` (natural CG from log analysis),
   `maxCurrent = 5.0` (safe authority), `angleFilterAlpha = 0.15`.
3. **R3 — Anti-stiction dither replaces piecewise stiction comp**:
   Replace `applyStictionComp()` with `applyDither()` that adds
   `±0.08 A * sin(2π * 40 Hz * t)`. Call-sites in `runAngleControlISR()`
   updated. No DC bias, no zero-crossing discontinuity.
4. **R4 — Per-second gains line in stream**:
   `GAINS:Kp=..,Ki=..,Kd=..,Setpt=..,MaxI=..,Filt=..,VelLoop=..,Dither=..@..Hz`
   once per second inside the existing stream block. Logs become
   self-documenting.
5. **R5 — Visible EEPROM-default warning**: After `loadSettings()` returns
   false, print an additional human-visible `⚠️  EEPROM INVALID — running
   from SOURCE DEFAULTS. Press 'k' to save once tuned.` line in addition to
   the existing `💾 No saved settings found (using defaults)` line (latter
   kept for grep-compatibility with log-parsers).
6. **R6 — `printTuningValues()` reflects dither**: The `MOTOR CONTROL` block
   prints dither amplitude + frequency instead of `Stiction Compensation`.
